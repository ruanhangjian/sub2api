# SubPilot fork 升级到官方 v0.1.144

## 修改背景

当前生产 Sub2API 使用自定义 SubPilot fork，基线早于官方 v0.1.144。为获取官方新版修复，同时保留 SubPilot select/report/probe 接入能力，创建独立分支将 SubPilot patch 移植到官方 v0.1.144 release tag 上。

## 分支

- 基线：`v0.1.144`
- 新分支：`feature/subpilot-v0.1.144`
- 未部署服务器。

## 冲突处理

- `Dockerfile`：官方 v0.1.144 已包含 `docs/legal` 复制逻辑，跳过旧的重复补丁。
- `.dockerignore`：官方 v0.1.144 已放行 `docs/legal`，跳过旧的重复补丁。
- `backend/internal/handler/openai_images.go`：保留官方新版图片上游错误分类和响应已写出保护，同时补回 SubPilot `lease_id` 与 failure report 上下文。
- `backend/internal/config/config.go`：同时保留官方 `gateway.openai_compact_model` 默认值和 SubPilot `gateway.subpilot.*` 默认值。

## 额外适配

官方 v0.1.144 新增 Grok media 路径，仍调用旧签名 `ReportOpenAIAccountScheduleResult(accountID, success, firstTokenMs)`。SubPilot fork 中该函数需要请求上下文以释放 lease 和上报失败，因此已在 `backend/internal/handler/grok_media.go` 中补齐：

- 账号选择后调用 `applySubPilotLease`
- failover 失败上报携带 `SubPilotFailContext`
- 普通失败上报携带 `SubPilotFailContext`
- 成功上报携带 `SubPilotFailContext`

## 测试结果

使用 Docker Go 镜像执行：

```bash
docker run --rm -v "$PWD":/src -w /src/backend \
  -e GOPROXY=https://goproxy.cn,direct \
  -e GOSUMDB=sum.golang.google.cn \
  golang:1.26.4-alpine \
  sh -lc '/usr/local/go/bin/go test ./...'
```

结果：通过。

## 风险点

- 本次只完成本地代码移植和后端测试，未构建生产镜像，未部署服务器。
- Grok media 是官方新版新增路径，已做编译适配；若后续希望 SubPilot 显式调度 Grok 账号，需要再确认 SubPilot 侧平台枚举和 UI 是否支持 Grok。
- 官方 v0.1.144 包含较多 upstream 变更，上线前仍建议先构建镜像并在测试实例验证 SubPilot select/report/probe 闭环。

- `GATEWAY_SUBPILOT_BASE_URL`
- `GATEWAY_SUBPILOT_TIMEOUT_MS`
- `GATEWAY_SUBPILOT_FAIL_OPEN`
- `GATEWAY_SUBPILOT_PROBE_SECRET`
